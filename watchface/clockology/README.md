# Clockology 조립 안내

Apple Watch SE 2세대 44mm(화면 368×448px)용 레이어 파일입니다.
`carbon/`(카본 블랙·레드)과 `rose/`(로즈골드) 폴더에 같은 이름의 파일이 들어 있습니다.

모든 PNG는 2배 해상도로 저장했습니다. 전체 화면 레이어는 736×896px이고, Clockology에서는 화면 전체(368×448)에 맞춰 넣으면 됩니다.

> Clockology의 메뉴 이름과 지원 기능은 앱 버전에 따라 다릅니다. 아래는 레이어 구성과 수치이고, 앱 안의 정확한 버튼 이름은 직접 확인하셔야 합니다.

## 방법 1 — 간단 버전 (레이어 4개)

기어와 투르비용은 멈춰 있고 침만 움직입니다. 먼저 이 방법으로 정상 동작을 확인하는 것을 권합니다.

| 순서(아래→위) | 파일 | 설정 |
|---|---|---|
| 1 | `simple_background.png` | 고정 이미지, 화면 전체 |
| 2 | `09_hand_hour.png` | 시침 회전, 화면 전체, 회전 중심 = 화면 정중앙 |
| 3 | `10_hand_minute.png` | 분침 회전, 화면 전체, 회전 중심 = 화면 정중앙 |
| 4 | `11_hand_second.png` | 초침 회전(부드러운 스윕), 화면 전체, 회전 중심 = 화면 정중앙 |

침 이미지는 모두 12시 방향을 가리키고, 회전축이 이미지 정중앙에 오도록 그렸습니다.

## 방법 2 — 전체 버전 (레이어 11개)

기어와 투르비용까지 움직입니다. 위치는 화면 정중앙을 (0, 0)으로 둔 값이고, 오른쪽과 아래쪽이 +입니다(단위: 포인트, 368×448 기준).

| 순서(아래→위) | 파일 | 표시 크기 | 중심 위치 (x, y) | 움직임 |
|---|---|---|---|---|
| 1 | `01_base.png` | 368×448 | 0, 0 | 고정 |
| 2 | `02_gear_barrel.png` | 96×96 | −50, −70 | 반시계, 약 8분에 1바퀴 |
| 3 | `03_gear_centre.png` | 64×64 | 0, 0 | 시계 방향, 10분에 1바퀴 |
| 4 | `04_gear_third.png` | 58×58 | +52, −40 | 반시계, 2분에 1바퀴 |
| 5 | `05_gear_fourth.png` | 50×50 | +58, +40 | 시계 방향, 1분에 1바퀴 (초침과 같은 회전) |
| 6 | `06_balance.png` | 60×60 | 0, +98 | 좌우 진동. 지원되지 않으면 초침과 같은 회전 |
| 7 | `07_cage.png` | 92×92 | 0, +98 | 시계 방향, 1분에 1바퀴 (초침과 같은 회전) |
| 8 | `08_overlay.png` | 368×448 | 0, 0 | 고정 (브리지, 숫자, 유리 반사) |
| 9 | `09_hand_hour.png` | 368×448 | 0, 0 | 시침 회전 |
| 10 | `10_hand_minute.png` | 368×448 | 0, 0 | 분침 회전 |
| 11 | `11_hand_second.png` | 368×448 | 0, 0 | 초침 회전(부드러운 스윕) |

앱에서 임의 속도 회전을 지원하지 않으면 2~4번 기어는 고정 이미지로 두고, 5번·7번만 초침 회전으로 설정해도 됩니다.

## 그 밖의 파일

- `reference_1010.png` — 10시 10분 상태의 완성 모습. 조립 결과를 비교하는 용도입니다.
- `../preview.html` — 움직이는 미리보기 원본.
- `../tools/export.js` — 레이어 PNG를 다시 만드는 스크립트 (`node tools/export.js`).

## 워치 설정

- SE 2세대는 상시표시 화면이 없어 손목을 내리면 화면이 꺼집니다.
- Apple Watch의 `설정 > 일반 > 시계로 돌아가기`에서 Clockology를 "1시간 후"로 두면, 손목을 들었을 때 이 페이스가 다시 보입니다.
