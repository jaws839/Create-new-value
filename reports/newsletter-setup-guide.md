# 뉴스레터 발송 셋업 가이드 (MIRU MEN)

> 남성 자기관리 레터를 실제로 발송하기 위한 단계별 셋업. 작성일 2026-09-26.
> 플랫폼은 국내 사용성 기준 **스티비(Stibee)** 또는 **메일리(Mailly)** 권장.

---

## 1. 플랫폼 선택

| 기준 | 스티비 | 메일리 |
|------|--------|--------|
| 강점 | 안정적 발송·자동화·기업 신뢰도 | 콘텐츠형 운영·아카이빙·크리에이터 친화 |
| 요금 | 무료 500명/월2회, 이후 구독자 구간별 유료 | 개인 무료, 마케팅 목적 기업 과금 |
| 추천 | 커머스 연동·자동화 우선 | 콘텐츠 브랜딩·초기 무료 우선 |

> 초기(구독자 <500)에는 **메일리 또는 스티비 무료 플랜**으로 시작 → 규모 확대 시 유료 전환.
> 요금·정책은 시점에 따라 바뀌므로 시작 전 공식 페이지 재확인 필수.

---

## 2. 셋업 단계

1. **계정 개설** — 발신자명 `MIRU MEN`, 발신 이메일(도메인 이메일 권장: news@도메인).
2. **발신자 인증** — SPF/DKIM 도메인 인증(스팸 처리 방지). 도메인 없으면 플랫폼 기본 발신 주소 사용.
3. **구독 폼 생성** — 이메일 1개 필드, 수신동의 체크. 리드마그넷("남성 그루밍 가이드 PDF") 연결.
4. **폼 임베드** — `index.html`/`men.html`의 뉴스레터 섹션 버튼을 구독 폼 URL로 연결(현재는 데모 동작).
5. **자동화(웰컴 시퀀스)** — 구독 즉시 ①환영+쿠폰(`MIRUMEN10`) → ③일차 루틴 팁 → ⑦일차 베스트 제품.
6. **창간호 발송** — `reports/newsletter-issue-01-draft.md` 내용을 편집기에 붙여넣고 발송.
7. **측정** — 오픈율·클릭률·구독 증가·쿠폰 사용 추적. UTM 파라미터를 모든 링크에 부착.

## 3. 법규 체크 (필수)

- [ ] **수신동의**: 명시적 동의 없이 발송 금지(정보통신망법).
- [ ] **광고 표기**: 제목에 `(광고)` 표기, 본문에 발신자 정보·연락처 명시.
- [ ] **수신거부**: 모든 메일에 1-클릭 수신거부 링크.
- [ ] **야간 발송 제한**: 광고성 정보는 21시~익일 08시 발송 시 별도 동의 필요.
- [ ] **개인정보 처리방침**: 이메일 수집·이용 목적 고지.
