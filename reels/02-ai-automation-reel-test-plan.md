## 0. 테스트 원칙

- **한 번에 하나만 바꾸기.** 3개 버전은 같은 자동화 사례와 같은 CTA를 쓰고, **훅과 앞부분 구성만 다르게** 합니다.
- **같은 조건으로 올리기.** 같은 요일·시간대에 올리고, 가능하면 Instagram의 **체험용 릴스(Trial reels, 팔로워가 아닌 사람에게만 먼저 보여주는 기능)** 를 씁니다. 계정에 이 메뉴가 보일 때만 가능합니다.
- **판단 기준을 미리 정하기.** 아래 지표를 올린 뒤 72시간 기준으로 비교합니다.

| 지표 | 보는 이유 | 위치 |
|---|---|---|
| 3초 유지율 (또는 건너뛰기 비율) | 훅 성능 | 릴스 인사이트 |
| 평균 시청 시간 / 완주율 | 구성 성능 | 릴스 인사이트 |
| 저장 수 | 정보 가치 | 인사이트 |
| 공유 수 | 확산력 | 인사이트 |
| 키워드 댓글 수 | CTA 성능 | 댓글 |
| 팔로워 증가 | 계정 전환 | 인사이트 |

## 1. 공통 소재 (예시)

> **"매일 아침 30분 걸리던 주문·문의 정리를 AI가 5분 만에 끝내게 만든 방법"**
> 예시: 스마트스토어·쿠팡 주문과 고객 문의를 모아서 → AI가 분류하고 답변 초안을 쓰고 → 노션/시트에 정리하고 → 카톡이나 메일로 요약 보고

- 실제로 돌아가는 자동화 화면을 녹화해서 씁니다. 목업은 쓰지 않습니다.
- 숫자(30분 → 5분, 주문 N건, 문의 N건)는 **직접 측정한 값만** 씁니다. 측정 전에는 자막에 [측정값] 자리만 비워 둡니다.

## 2. 버전 A — "AI 직원 회의" (벤치마크의 대결 구조를 그대로 적용)

| 구간 | 자막 | 화면 |
|---|---|---|
| 0–3초 | AI 직원 4명한테 / 우리 가게 아침 업무를 맡겼어요 | "AI × 4" 카드 → 역할 카드 4장 펼쳐짐 |
| 3–5초 | 사장님 혼자 하면 / 아침 30분이 그냥 사라지잖아요 | 주문·문의 알림이 쌓이는 화면 |
| 5–10초 | 한 명은 주문을 모으고 / 한 명은 문의를 분류해요 | 좌우 분할: 주문 수집 AI / 문의 분류 AI |
| 10–15초 | 한 명은 답변 초안을 쓰고 / 마지막 한 명이 검토해요 | 답변 초안 → 검토 AI가 빨간 펜으로 수정 |
| 15–20초 | 실제로 오늘 아침 / 주문 [N]건, 문의 [N]건 | 실제 실행 로그, 숫자 카운터 |
| 20–25초 | 결과는 이렇게 / 한 장으로 와요 | 노션/카톡 요약 보고 화면 (결과물 공개) |
| 25–28초 | 코딩 없이 / [도구명]으로 만들었어요 | 도구 로고 + 비용 조건 정확히 표기 |
| 28–35초 | 설정 방법을 / 전부 문서로 정리했어요 / 댓글에 "자동화" 남겨주세요 | 가이드 PDF 표지 → DM 도착 연출 |

## 3. 버전 B — "전/후 비교" (시간 절약 숫자로 시작)

| 구간 | 자막 | 화면 |
|---|---|---|
| 0–3초 | 30분 → 5분 / 매일 아침 이 차이 | 왼쪽 수동 작업(빨리감기) / 오른쪽 자동 실행 |
| 3–8초 | 원래는 이걸 / 하나하나 복사했어요 | 엑셀에 복붙하는 화면 |
| 8–25초 | (버전 A의 5–25초 구간과 같은 흐름) | |
| 25–35초 | (버전 A와 같은 CTA) | |

## 4. 버전 C — "반전/결과물 먼저" (결과물을 첫 화면에)

| 구간 | 자막 | 화면 |
|---|---|---|
| 0–3초 | 출근하면 이게 / 이미 와 있어요 | 오늘의 요약 보고서 화면을 확대 |
| 3–6초 | 제가 한 건 / 아무것도 없어요 | 빈 책상 / 커피 |
| 6–25초 | (버전 A의 5–25초 구간과 같은 흐름) | |
| 25–35초 | (버전 A와 같은 CTA) | |

## 5. 편집·디자인 규칙 (벤치마크에서 가져온 것)

- 1~2초마다 화면 전환, 같은 화면 3초 이상 금지
- 자막은 한 줄 12자 안팎, 2~6어절씩 끊기
- 장면마다 숫자 1개 이상
- 실제 도구 화면 위주로 구성 (자동화 실행 로그, 노션, 시트, 카톡 요약)
- 대비 색: 수동 = 회색/빨강, 자동 = 브랜드 색/초록
- 결과물은 "파일"이나 "보고서 한 장"처럼 손에 잡히는 형태로 보여주기
- 마지막 3초: 받게 될 가이드 표지를 미리 노출
- 길이 30~40초

## 6. 캡션 템플릿

```
매일 아침 [N]분 걸리던 주문·문의 정리, 이제 AI가 [N]분 만에 끝내요.

팁 하나: 자동화하기 전에 "매일 똑같이 반복하는 클릭"부터 적어 보세요.
그게 곧 AI에게 맡길 업무 목록입니다.

💬 "자동화" 댓글 ➡️ 설정 순서 + 바로 쓰는 프롬프트 [N]개 담은 가이드 📩

#AI자동화 #업무자동화
```

## 7. 정직성 체크리스트 (올리기 전)

- [ ] 숫자는 모두 직접 측정한 값인가
- [ ] "무료"라고 썼다면 유료 요금제나 사용량 조건까지 적었는가
- [ ] 다른 사람이 만든 도구나 템플릿이면 출처를 밝혔는가
- [ ] 공식 로고·행사 이미지를 관련 없이 쓰지 않았는가
- [ ] 댓글 키워드로 약속한 가이드가 실제로 준비되어 있는가
- [ ] DM 자동 발송은 Instagram 정책을 지키는 공식 연동 도구로 하는가
