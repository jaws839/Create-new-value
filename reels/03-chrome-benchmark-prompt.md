# Claude in Chrome 벤치마킹 수집 프롬프트

## 사용 방법

1. PC의 Chrome에서 Instagram에 로그인합니다.
2. `instagram.com`을 열어 둔 상태에서 Claude 옆 패널을 엽니다.
3. 아래 프롬프트를 그대로 붙여 넣습니다.
4. 결과 표를 이 저장소 대화에 붙여 주시면 `02-ai-automation-reel-test-plan.md`를 v2로 고칩니다.

---

## 프롬프트 (복사해서 붙여넣기)

```
목표: "AI 업무자동화" 분야에서 조회수가 가장 높은 인스타그램 릴스를 찾아,
내 릴스를 만들 때 참고할 구성·편집·디자인 요소를 정리하는 것.

규칙:
- 읽기만 할 것. 좋아요, 팔로우, 댓글, DM, 저장은 절대 하지 말 것.
- 화면에서 확인한 숫자만 적고, 확인 못 한 값은 "확인 불가"로 적을 것. 추측 금지.
- 음성은 들을 수 없으니 자막과 화면 텍스트만 근거로 할 것.

1단계 — 후보 수집
- 다음 해시태그와 검색어로 릴스를 찾아라:
  #AI자동화 #업무자동화 #자동화 #claudecode #클로드 #챗GPT활용 #n8n #노코드
- 상위 노출 계정의 프로필 > 릴스 탭에서 썸네일에 표시된 조회수를 확인하라.
- 최근 90일 안에 올라온 릴스 중 조회수 상위 10개를 골라라.
  (90일 안에 충분하지 않으면 180일까지 넓히고, 그렇게 했다고 표시)

2단계 — 릴스별 기록 (10개 모두)
| 항목 | 내용 |
|---|---|
| URL | |
| 계정 / 팔로워 수 | |
| 게시일 | |
| 조회수 / 좋아요 / 댓글 | |
| 길이(초) | |
| 첫 3초 자막·화면 (훅) | |
| 훅 유형 | 발견형 / 전후비교 / 결과물먼저 / 질문형 / 반전 / 기타 |
| 구간별 구성 | 0-3초, 3-10초, 10-20초, 20초-끝 각각 무엇을 보여주는지 |
| 컷 전환 빈도 | 대략 몇 초마다 화면이 바뀌는지 |
| 자막 스타일 | 위치, 글자 크기, 색, 한 번에 보이는 글자 수 |
| 화면 소재 | 실제 도구 화면 / 얼굴 출연 / 목업 / 스톡 영상 |
| 숫자 사용 | 화면에 나온 숫자들 |
| CTA | 댓글 키워드 / 팔로우 / 저장 / 링크 / 없음 |
| 캡션 구조 | 첫 줄, 팁 유무, CTA, 해시태그 개수 |
| 댓글 ÷ 좋아요 비율 | 계산값 |

3단계 — 종합
- 10개에서 공통으로 나타나는 패턴 5가지 (몇 개 릴스에서 나왔는지 함께 표기)
- 조회수 상위 3개에만 있고 나머지에는 없는 차이점
- 반대로, 조회수가 높아도 따라 하면 안 되는 요소 (과장, 출처 누락, 오해를 부르는 이미지 등)
- "AI 업무자동화" 릴스에 바로 적용할 훅 문구 5개 제안

출력은 마크다운 표와 목록으로 정리해 줘.
```

## 결과를 받은 뒤 할 일

1. 결과 표를 `reels/benchmark-data-YYYY-MM-DD.md`로 저장합니다.
2. 공통 패턴이 지금의 테스트 구성안(버전 A/B/C)과 다르면 해당 버전의 훅과 구성을 바꿉니다.
3. 조회수 상위 3개의 훅 유형을 버전 하나에 반영해 **버전 D**를 추가합니다.
